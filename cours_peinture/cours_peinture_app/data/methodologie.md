Methodologie
------------

1. Imprimatura rapide de gris (bleu outremer + rouge d'oxyde transparent) avec du médium.
Supprimer l'excédent avec du sopalin.

2. Traits de construction avec une peinture transparente (par exemple alizarin crimson) + médium.
Faire des segments fins mais longs afin de structurer.
Chercher des formes simples les plus grandes possibles.

3. Valeurs sombres (utiliser toutes les couleurs sauf le blanc). Pour faire un noir profond mélanger bleu outremer + rouge d'oxyde transparent (+ éventuellement alizarin crimson).
On peut dans un 1er temps faire tous les sombres identiques, et apporter des variations de valeur et couleur dans une 2eme passe.

4. Demi-tons. (utiliser toutes les couleurs y compris le blanc). 
Penser à séparer les pinceaux qu'on utilise pour les clairs des pinceaux qu'on utilise pour les sombres.

5. Tons clairs (ignorer pour l'instant les spéculaires). A ce niveau la toile est complètement couverte.

6. Redéfinir les sombres, puis les clairs, et alterner entre les 2 jusqu'à avoir des valeurs correctes (plisser les yeux !).

7. Faire les spéculaires.

Conseils généraux
-----------------

- Régulièrement reculer
- Pour baisser la saturation d'une couleur la mélanger avec sa complémentaire
- Appliquer des touches franches
- Du général vers le particulier (donc grosses brosses le plus longtemps possible)
- Essayer de garder de la transparence dans les sombres et mettre de la matière dans les clairs

Ajuster une couleur
-------------------

Je n'ai pas de mélange tout fait à donner pour la couleur de peau. 
Le mieux est de commencer par un mélange de blanc et de la couleur qui vous parait la plus proche de ce que vous voyez.
Puis itérer 
- si trop clair / sombre ->  ajuster la proportion de blanc
- si trop saturé -> mélanger avec complémentaire
- si trop 'chaud' -> ajouter couleur froide (bleu ou vert)
- si trop 'froid' -> ajouter couleur chaude (rouge, orange, brun)

Si vous êtes mal à l'aise avec les mélanges de couleur je vous conseille de faire un nuancier.
