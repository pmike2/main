Strategy : Génération des .obj dans Blender :
- générer un material par composant du modèle, de type Diffuse BSDF
- Modifier Viewport Display
- Choisir la couleur noire si l'on veut que ce composant prenne la couleur de l'équipe
- Orienter vers x positif puis lors de l'export : choisir Forward Axis = Y, Up Axis = Z
- cocher Triangulated Mesh

Blender :
s (scale), r(rotate), g(translate) puis x, y, z pour faire selon x , y ou z

tab : edit mode
ctrl + tab : pose mode

shift + a : add

a : select all
alt + a : deselect all

select vertices in edit mode; ctrl + g -> "assign to new group" pour créer un vertex group à partir de ces vertices

viewport overlays / turn on wireframe : pour voir les aretes

numpad : change view

rigging : https://www.youtube.com/watch?v=DDeB4tDVCGY
add armature
Data / viewport display / in front pour afficher armature devant le reste
e : extrude bone
shift + d : duplicate bones
ctrl + p : make parent
alt + p : unmake parent (disconnect)
nommer les jambes bras gauche avec suffix .L, puis click droit symmetrize : crée les .R
object mode ; select model ; click droit armature : parent / armature defform / automatic weights
pose mode ; select armature; déplacement rotation se reflète sur le modèle !

on peut aussi créer les vertex group à la main mais il faut que les noms des vertex group correspondent aux noms des bones
et il faut que le mesh ait un modifier de type armature

dans menu principal à droite de armature : show names -> affiche le nom des bones

weight painting :
1 - object mode, select armature
2 - shift click select object
3 - ctrl tab -> weight paint mode
barre du haut / weights / assign automatic from bones
-> permet de repartir de ce qu'on a fait avant avec automatic weights
brush tool options / auto normalize : pour que la somme des weights fasse tjrs 1
brush tool symmetry : utile pour bras / jambes
f : change brush size
dans menu principal à droite : Vertex Groups : on peut switcher entre les bones pour peindre leur influence sur l'objet sélectionné

rigid rigging :
fonctionne uniquement quand on a des objets distincts
1 - object mode, select un objet (par ex la tête)
2 - shift click armature
3 - ctrl tab -> pose mode
4 - select bone
ctrl - p : set parent to bone -> l'objet est maintenant attaché au bone

cf https://blenderartists.org/t/bone-extrusion-problem/526543
si un bone ne veut pas bouger et ne fait que des rotations il faut :
- passer en edit mode
- sélectionner le bone
- dans l'onglet à droite icone bone, partie Relations, unclick 'connected'

animate :
https://www.youtube.com/watch?v=IAiTYaiZmY0

pose mode
select bone(s) (a pour all)
press i : insert keyframe
move / rotate ; change time mark ; i : insert another keyframe
maintenant quand on bouge le time mark on a une anim !

bloc timeline en haut à gauche ou droite icone '+' , permet d'afficher plusieurs timelines
-> dope sheet + timeline bien

dans dopesheet : a : select all, puis x : supprime tous les keyframes

markers : utiles si on veut mettre plusieurs anims dans un .blend (marcher, courir, ...)
Marker / add marker pour ajouter un marker, puis on peut le renommer en le sélectionnant puis rename marker
